## Overview

This repository serves as a centralized hub for foundational AI and machine learning study materials. Each handbook is designed to provide clear, practical, and professional coverage of essential concepts for learners and practitioners.

Target audience: students, researchers, engineers, and professionals exploring AI, ML, and GenAI workflows.

---

## Resource Library

### Machine Learning

**📄 [ML_Algorithms_Professional_Handbook.pdf](./ML_Algorithms_Professional_Handbook.pdf)**

A practical guide to machine learning algorithms, including:
- supervised and unsupervised learning
- regression and classification methods
- clustering and dimensionality reduction concepts
- evaluation metrics and model selection

### Deep Learning

**📄 [Deep_Learning_Professional_Handbook.pdf](./Deep_Learning_Professional_Handbook.pdf)**

An in-depth exploration of neural networks and deep learning, including:
- neural network fundamentals and architectures
- CNNs, RNNs, and transformer-related concepts
- backpropagation, optimization, and regularization
- model training best practices and debugging workflows

### Large Language Models

**📄 [LLM_Professional_Handbook.pdf](./LLM_Professional_Handbook.pdf)**

A professional guide to large language models, covering:

- pretraining, fine-tuning, and inference strategies
- prompt engineering and optimization techniques
- deployment considerations and real-world use cases
